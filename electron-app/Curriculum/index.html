Robot Arm — Interactive Curriculum

BTEC Level 3 Engineering  ·  16 Modules  ·  Theory, Practice & Software Activities

Software required: These modules link directly to the Robot Arm Control Application. Launch the Electron app (or open via browser at your Pi's IP address) before starting any practical activity.

How each module works

Each module has four parts: Theory — short explanations with diagrams · Software Activity — step-by-step tasks using the control app · Worksheet — questions and observations to record · Quick Check — two or three multiple-choice questions to test understanding.

Worksheet Tools

Actions apply to all saved worksheet answers on this computer.
